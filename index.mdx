## What do you want to do?

<CardGroup cols={2}>
  <Card title="I just want to use AI" icon="bolt" href="/api-gateway/windows">
    **API Gateway Path** — get an API key and connect Morpheus inference to
    your application, AI agent, OpenClaw instance, or other compatible client.
    No wallet, no local software required.
  </Card>
  <Card title="I want to use Morpheus natively" icon="network-wired" href="/native-path/desktop-app">
    **P2P / Native Path** — run the Morpheus router locally, connect your
    wallet, discover providers, stake MOR, and access inference directly
    through the network.
  </Card>
</CardGroup>

## Not sure which fits? Compare them

| | API Gateway | Native P2P |
|---|---|---|
| Setup difficulty | Easy | More involved |
| Wallet required | No | Yes |
| MOR required | Depends on plan | Yes |
| Local software required | No | Yes |
| Direct P2P routing | No | Yes |
| Best for | Applications, agents, developers | Full Morpheus ecosystem experience |
| Desktop GUI available | No | Yes |
| CLI support | Via compatible clients (OpenClaw) | Yes (morctl) |
